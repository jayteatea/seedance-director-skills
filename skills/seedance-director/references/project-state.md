# 保存与接续

Skill不提供软件数据库、自动永久记忆或精确暂停API。宿主支持停止时由用户控制；恢复时只根据当前可见对话、已保存正文和公开交接记录，不要求恢复隐藏思维链，不自动重试收费请求。

用户只要文字时直接在聊天交付。用户要求保存且工作目录明确时，将成果放其指定项目目录，不默认写入本Skill仓库或个人知识库。多个项目各自保存，不跨项目继承人物、剧本或授权。

建议用四类独立Markdown产物：执行方案、分镜、精修建议、最终提示词。新修改保存新版本，不覆盖旧稿；文件名可用stage-vNN，不把命名规则变成创作门禁。没有实际写文件成功就只说“已在对话给出”，不能声称“已存档”。

简短交接记录只记：项目/稿件路径与版本、当前阶段、已确认要求、当轮授权范围、已完成/未完成部分、下一步。恢复先核对文件存在和正文，找不到就说明，不靠记忆猜版本。

如用户要求积累经验，可记录“观察到的问题、证据位置、原因（确定或待核实）、改法、复用边界”，保存普通UTF-8 Markdown供Obsidian读取。不要存API密钥、完整私人聊天或内部思维链；不要自动上传到GitHub。
