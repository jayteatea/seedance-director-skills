# 精修检查与授权修订

精修检查的产物是建议，不是替用户修改。先确定被审稿件和范围；清楚则直接工作，不重复索要版本。只见到部分稿就限定结论，不声称整片通过。

依据当前要求与原文，检查：

1. 剧情、对白、指定同镜、动作次数是否保留；是否把“不描述人物外观”误解成“不拍人”。
2. 时间是否可容纳对白、动作和可读反应；重复与拖沓在哪里；快速是否仍清楚。
3. 固定空间、视线、轴线、动作桥、道具与首尾状态是否连续。
4. 景别、机位、运动的动机与路径是否明确，是否单调或掩盖事件。
5. 表演是否符合人设、触发时点和可见范围，是否过度堆细节。
6. 自适应全局参数是否确实进入逐镜；任意复制一组是否自足。

每项给“位置/原文依据 → 问题与影响 → 最小建议 → 取舍”，区分确定矛盾、时间估算与审美选择。建议编号便于选择，不强凑问题或虚构量化评分。

明确“尚未修改原稿”。用户采纳哪些就改哪些，不将采纳一条变成采纳全报告。重大修改依赖相邻场景且范围未授权时，暂停受影响的后续处理等待确认，不擅自继续铺开。

仅整理表达不能称“已精修”。明确按确认意见修改后，可以说明实际改动，但不能凭“完成”标签声称做过独立专业审阅。自评不等于外部专家或真实视频验收。

常见误区：为了快删剧情；为了镜数打碎连续镜头；为了细腻每镜加微表情；为了可复制只保留简版；为了校验通过自动重写未授权内容。这些都不属于正常精修。
